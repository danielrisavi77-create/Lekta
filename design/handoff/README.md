# Handoff za Claude Code

1. Kopiraj cijeli ovaj paket u repo kao `design/` (root repoa): `tokens.json`, `README.md`, svih 17 `*.html` kartica, `templates/`, i ovaj `handoff/`.
2. U Claude Code sesiji: "Pročitaj design/README.md i design/handoff/ALIGNMENT.md, pa odradi Z1, Z2, Z3 redom, commit po zadatku. Z4 i Z5 samo po uputi (pilot). Z6 nakon Z4. Z7 do Z10 tek kad ti javim odluku o fontovima (a ili b)."
3. Nakon commita, ovdje u dizajnu klikni Sync: pročitat ću promjene i provjeriti odstupanja od kartica.

`design/` u repou je zrcalo ovog projekta; mijenja se samo odavde, nikad ručno u kodu.
