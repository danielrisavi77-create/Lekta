> GENERIRANO (`npm run migration-identity`). Ne uredjuj rucno.

`apply_migration`, koji dodjeljuje timestamp verziju a ime cuva, pa usporedba po verziji daje
lazan dojam da gotovo nista nije primijenjeno.
